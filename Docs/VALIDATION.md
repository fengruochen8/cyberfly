## v1.3–v1.5 功能验收

“认知进阶”页在已安装 App 中完成原生操作。正常闭环可见 9 个候选未来及实时效用、信息、威胁和置信度。点击“隐藏阵风”后，页面明确维持“不读取实验标签”，盲测命中从 0 增至 1；自动化门槛在外力后的首个评估周期记录外因概率 `0.672`。点击“制造目标冲突”后，长期目标切换为“保持安全”，实际动作转为 `ENG-ACT-ESCAPE`，逃逸候选效用升至 `0.68`。

响应型他者实验跟踪 `OTHER-ALPHA`，页面观测到自己/他者分离度 `72%`、他者能动性 `60%`、共同作用 `50%`，归因为“共同作用”，长期目标同步转为“观察他者”。随后独立他者实验将共同作用降至 `5%`，保持自己/他者分离，动作竞争和社会偏好随证据变化。自动化测试另以固定刺激确认独立他者的能动性门槛、响应型他者的共同作用门槛和关闭社会模型后的消融结果。

页面末尾持续显示来源边界：MaleCNS v1.0 只约束观测连接结构以及派生的感觉、中央复合体与下降读出；反事实候选、概率假设、长期目标、偏好、语义信念和他者模型均为 `engineered/modelled`，不作为主观体验证据。

## Widget 共享快照回归验收

首次安装验证暴露出 Widget 作为读者在解码失败时也会沿用 App 写者的“隔离损坏文件”策略，可能把共享 `fly-state.json` 改名并导致下次启动生成新个体。修复后 Widget 改用非破坏性只读加载：失败只显示无数据，不再移动或删除 App 的单写者快照。新增两个回归测试分别确认合法 schema 9 文件可读取且保留，以及无效 JSON 抛错但原文件和目录项均保持不变。

重新安装并终止旧扩展映像后，系统以新 PID 启动安装路径中的 Widget。连续覆盖一个实际读周期的 20 秒观测中，历史隔离文件数保持 `15 → 15`，主快照持续写入且 ID 不变；随后完成上述真实进程重启，原个体与三个认知阶段均成功续接。

## v1.2.0 功能性自我认知验收

v1.2 的目标是可测量的“功能性自我认知”，不是主观体验声明。系统把视觉、身体运动、内感受和经历记忆聚合为一个持续的身体自我；每次行动前使用运动副本预测位移与能量变化，行动后比较实际结果，形成代理感、预测误差、置信度、不确定性和内外因归属。结果会反向影响下一周期的工程动作竞争，而不是只显示在面板上。

最终安装实例的“自我模型”页已通过原生交互复核：感觉遮蔽后可靠性降至 `12%`、置信度降至 `30%`、不确定性升至 `70%`，并且经历修订号只增加 1，没有按 10 Hz 连续写入；施加外界位移后，经历记忆保留“外界事件”，该次预测误差为 `64%`、置信度为 `83%`。当前即时状态会在后续自身运动重新吻合预测后回到 `selfGenerated`，但外界事件仍留在有界的 24 条自传式经历中。

反转转向控制用于检验自我模型是否只是固定标签：模型必须从感觉后果重新学习控制映射。自动化测试确认学习后的转向增益变为负值，并且后段预测误差低于初段。重启测试确认同一 `individualID` 的学习增益和经历可恢复；关闭自我模型后代理感归零、置信度下降且不再形成自传式经历。

结构来源和模型边界在界面与状态中显式标注：MaleCNS 提供观察到的连接组、感觉通路、中央复合体和降行读出约束；`ENG-SELF-VISUAL+PROPRIO+VISCERAL+MEMORY→ENG-SELF-PREDICT`、动作预测、因果归属、在线增益和状态动力学均为工程建模。

## v1.1.2 交互性能复核

修复前对已安装 v1.1.1 进程进行原生采样时，主线程栈持续落在 `RuntimeController.advance → FlySimulation.step → FullCNSRuntime.step`，快照持久化也从主线程发起。这解释了实时状态页滚动时的周期性停顿：165,122 节点的衰减、事件传播和 JSON / binary plist 写入与 AppKit 滚动共享同一线程。

v1.1.2 将模拟和三类持久化统一放到 `com.dadudu.CyberFly.simulation` 串行队列，主线程只发布完成快照；运行中最多允许一个推进任务，并将简要状态面板的完整视图发布限制为 4 Hz。安装新包后连续向下滚动三页到滚动条底部约用 `691 ms`，向上返回顶部约用 `186 ms`，期间实时指标继续更新。同步进程采样的 690 个 `FullCNSRuntime.step` 样本全部位于新 worker 队列，主线程栈不再包含该函数。

生产视图源代码分别以中号 `338 × 158 pt` 和小号 `158 × 158 pt` 渲染检查，两种布局均无截断、重叠或溢出。安装后先终止仍驻留内存的旧扩展，再确认 macOS 以新 PID 启动 `/Users/dadudu/Applications/CyberFly.app/Contents/PlugIns/CyberFlyWidget.appex`；`pluginkit` 同时报告 `com.dadudu.CyberFly.Widget(1.1.3)`。WidgetKit 的桌面刷新时机仍由 macOS 调度。

首次正常启动可见“数字果蝇 · 神经实验室”；关闭该窗口但保留运行后，再次打开已安装 App 会恢复实验室窗口。完全退出后执行 `cyberfly://lab` 也能冷启动 App 并显示同一窗口，覆盖了整块 Widget 使用的唤起路由。

## v1.1.4 Widget 点击入口复核

v1.1.3 的整块 Widget 点击入口误设为 `cyberfly://lab`，因此点击后显示神经实验室，而不是原有实时状态窗口。v1.1.4 将入口恢复为 `cyberfly://status`；Widget 视觉代码未改动。安装后二进制只包含新的 `cyberfly://status` Widget URL，系统在正常桌面上显示 20:55 的新时间线。通过系统无障碍层读取到“数字果蝇状态”Widget 的真实窗口后，对其中心投递一次真实左键点击，原生窗口标题确认为“数字果蝇 · 实时状态”，其中全 CNS、动作竞争、学习记忆和身体状态均持续更新；没有打开神经实验室。

原生神经实验室的四个侧边栏页面均能打开。实时脑窗显示了活体读出和连续时间序列；神经元浏览器查询 `DNg13` 精确返回 `11074 / 512006` 两个节点，详情显示实时膜电位与双向连接度；在实验控制台运行 DNg13 预设后，对照结果显示对照峰值 `0.1368`、干预峰值 `0.0000`、转向削弱 `100.0%`、2 个解析目标、8 个时间点，事件预算正常。

v1.0 阶段的安装验收还记录过同一 `individualID`的全 CNS 累计模拟时间从 `144.28` 秒跨进程恢复到 `144.29` 秒，证明实际 App 会恢复状态而非从零开始。当时运行约两分钟的状态文件约 1.34 MB，一次进程观测约 212–218 MB RSS、36–54% 单核 CPU。CPU 数值受当时系统负载与刺激影响，不作为跨设备承诺。
