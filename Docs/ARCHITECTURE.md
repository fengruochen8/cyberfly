# 数字果蝇架构基线

## 目标

数字果蝇是一只由持续内部状态和神经活动驱动的 macOS 桌面动物。用户提供食物、触觉和环境变化，但不能直接命令它播放行走、飞行或梳理动作。

## 数据真实性

所有数据和参数使用以下来源标签：

- `observed`：MaleCNS 直接观测的神经元、连接、突触数量和骨架。
- `predicted`：MaleCNS 提供的神经递质预测。
- `literature`：论文或实验文献参数。
- `fitted`：通过行为和身体模拟校准的参数。
- `assumed`：暂无可靠生物数据的工程假设。

视觉子图从官方 MaleCNS v1.0 Feather 文件提取
`LoVP92 → VES200m → DNg13` 回路：27 个神经元、322 条回路内连接。
其中 `LoVP92 → VES200m` 合计 687 个突触、`VES200m → DNg13` 合计
362 个突触、`LoVP92 → DNg13` 合计 54 个突触。神经元身份与突触权重是
`observed`，递质身份是 `predicted`。

电信号不是 MaleCNS 数据的一部分。运行时使用 2 ms 子步长的轻量 LIF 模型生成
膜电位与放电，时间常数、阈值、突触效应和被完整 CNS 省略的 DNg13 基线输入属于
`literature`/`assumed`。当前只让三条前向路径参与动力学；提取文件仍保存全部 322
条连接，便于后续扩大模型。左右 DNg13 放电率之差只作为桌面转向修正，不代表已经
复现完整视觉行为。

### 嗅觉学习子图

V2 另外提取 `DM1/DM2 → KC → MBON01/11 ↔ PAM01/PPL101` 子图：

- 1,426 个具有真实 `bodyId` 的 MaleCNS 神经元，其中包含 1,240 个同时连接选定 PN 和 MBON 的 KC。
- 17,744 条回路内连接；节点身份与每条连接的突触数为 `observed`，递质为 MaleCNS `predicted`。
- 运行时保留每个 KC 观测到的 DM1/DM2 输入和 MBON01/11 输出突触数，以输入排名选择 5% 稀疏活跃 KC。
- 奖励信号激活 PAM01 通道并抑制活跃 `KC → MBON01` 的有效权重，使输出倾向趋近；惩罚信号激活 PPL101 通道并抑制活跃 `KC → MBON11` 有效权重，使输出倾向回避。
- 与当前气味关联的 KC 才会被改写；相反强化逐步恢复旧通道并建立新价性。每个 KC 的两组有效权重单独保存。

PAM/PPL1 对奖励/惩罚的分工、活跃 KC 与多巴胺同时出现时对 `KC → MBON` 的抑制，以及 MBON 群体价性对行为选择的偏置有文献依据。实现中的具体气味标签、稀疏比例、学习率、有效权重下限和反转速度是 `fitted`/`assumed`，不是 MaleCNS 里的观测值。参考：[Aso et al., 2014](https://elifesciences.org/articles/04580) 与 [Bennett et al., 2021](https://pmc.ncbi.nlm.nih.gov/articles/PMC8105414/)。

### 全动作神经控制层

`0.4.0` 把原来的启发式候选分数、行为持续计时器、按行为硬编码速度和直接朝目标转向，替换为
`ENG-SENSORY → ENG-ACTION-WTA → ENG-DESCENDING` 有状态速率网络：

- 18 个感觉/内感受单元编码能量、疲劳、警觉、梳理需求、压力、好奇、食物气味/接触/方位、记忆价性、威胁、触觉、新奇、污染和 MaleCNS 视觉转向输出。
- 12 个互相抑制并带短时自激的动作群，一一对应全部 `FlyBehavior`。每步由神经竞争选择动作；随机性只以神经噪声进入网络。
- 6 个下降运动输出直接产生前进速度、转向角速度、振翅、进食、梳理和休息门控，另有竞争性抑制与复发状态，共计 38 个控制单元。
- 能量、疲劳和污染是身体状态；它们只能作为下一步的神经输入。身体层不选择动作，也不根据行为枚举设置速度或转向。
- 边界碰撞反射属于环境物理约束；“救活”属于用户对模拟生命状态的外部干预，二者都不是果蝇自主动作。

上述 38 个控制单元及其动力学、连接权重和运动标定全部是 `fitted/assumed`，没有借用真实神经元名称。
MaleCNS 视觉与学习回路仍分别标为 `observed`/`predicted` 数据约束。快照因此使用
`male-cns-neural-embodied-v0.4`，不能标为 `male-cns-connectome`。

## 运行边界

```text
桌面环境 → 感觉/内感受神经元 → 动作群 WTA → 下降运动神经元 → 身体/物理 → 感觉反馈
               ↑                  ↑               ↓              ↓
          MaleCNS 视觉         MaleCNS 记忆      神经门控      能量/疲劳
                                      └────────→ 状态快照 → 面板 / WidgetKit
```

桌面宿主持续运行模拟并每秒原子写入一份只读快照。WidgetKit 扩展只读取快照，不运行神经模拟，也不改变果蝇状态。宿主在显示状态发生明显变化时请求 `WidgetCenter.reloadTimelines`；实际桌面小组件刷新仍由 macOS 调度。

桌面水果是一份有限资源，而不是永久坐标。进食时它按接触强度消耗，形状随剩余份量缩小；放置 8 分钟后鲜度和可食强度线性衰减并显示腐败，12 分钟后移除。过期检查即使在暂停模拟时也按墙上时间继续。

## 状态语义

- `valence`：短时间内的愉悦或不适倾向。
- `wellbeing`：较长时间尺度的整体满足程度。
- `hunger`：由能量反向推导的寻食驱动力。
- `curiosity`：对新刺激和探索的内部驱动力。
- `arousal`：警觉与行动增益。
- `groomingNeed`：由自然积累和外部污染产生的梳理需求。

这些词是对模型内部数值的可读解释，不是对主观意识的证明。
