# 数字果蝇 v1.5 架构

## 运行边界

```text
桌面环境与身体状态
        │
        ▼
视觉 / 嗅觉 / 味觉 / 触觉 / 本体 / 饥饿 / 强化编码  [derived/fitted]
        │
        ▼
MaleCNS v1.0 全 CNS 图：165,122 节点，25,563,197 边  [observed/predicted]
        │
        ├── 群体状态、调制物、全图事件传播                [modeled]
        ├── LoVP92 → VES200m → DNg13 可审计视觉读出      [mixed]
        ├── 神经实验室：实时观测 / 节点查询 / 隔离 A/B   [mixed]
        └── 感觉 / 中央复合体 / 下行 / 运动群读出         [derived/fitted]
                              │
                              ▼
视觉 + 本体 + 内脏 + 记忆 → ENG-SELF-PREDICT → 误差 / 归因 / 置信度 [engineered/modelled]
                              │                         │
                              └──────── 反馈 ───────────┘
                                                        ▼
反事实候选 / 元认知 ↔ 长期目标 / 语义自我 ↔ 他者模型                 [engineered/modelled]
                              │
                              ▼
21 感觉 + 3 自我 + 5 认知输入 → 12 动作群 WTA → 6 下降输出 + 2 竞争状态，共 49 单元 [fitted/assumed]
                              │
                              ▼
身体与桌面物理 → 下一周期感觉反馈
        │
        └── schema 9 原子 JSON 快照 → 状态面板 / 自我知识 / WidgetKit
```

全 CNS 图直接参与每个模拟周期，但图本身不能唯一决定动作，更不能直接产生自我认知。缺少受体表达、细胞动力学、感觉变换、肌肉和身体力学时，从连接组到行为仍是不适定问题。因此 v1.5 保留明确命名为 `ENG-*` 的工程层，并把全 CNS 读出作为它的结构约束输入；`ENG-SELF-PREDICT`、反事实、语义自我和他者模型都是工程模型，不是从 MaleCNS 数据发现的“意识神经元”。

## 数据层

`Scripts/build_malecns_full_graph.py` 读取三份 MaleCNS v1.0 Feather：注释、递质预测和连接权重。编译过程只选择 `status == Traced` 的 `165,122` 个节点，按 `bodyId` 升序编号，并精确聚合两个已追踪端点之间的每一组 `body_pre/body_post` 权重。

产物由固定宽度节点表、出边 CSR 和入边 CSC 组成：

| 文件 | 内容 | 整数格式 |
| --- | --- | --- |
| `nodes.bin` | body ID、角色位、递质、半球、质量、胞体坐标、递质置信度 | little-endian，32 bytes/节点 |
| `out-offsets.bin` | CSR offset | `UInt64` |
| `out-targets.bin` | CSR 目标节点 | `UInt32` |
| `out-weights.bin` | CSR 聚合突触数 | `UInt32` |
| `in-offsets.bin` | CSC offset | `UInt64` |
| `in-sources.bin` | CSC 来源节点 | `UInt32` |
| `in-weights.bin` | CSC 聚合突触数 | `UInt32` |

`FullCNSGraph` 使用 memory mapping 读取约 397.6 MiB 图文件。SwiftPM 从资源 bundle 加载，Xcode App 与测试从 `CyberFlySimulation.framework` 的资源 bundle 加载。初始化检查格式、固定图 SHA、文件大小、offset 单调性和运行时会访问的目标索引边界；深度校验再核对 7 个文件 SHA、完整图 SHA、节点排序、全部索引边界与双向突触总和。

角色位不是 MaleCNS 原生的统一功能标签。它们由 `superclass/class/subclass/type/instance` 等观测注释通过可审计文本规则推导，来源等级为 `derived/fitted`。神经递质名称来自数据集预测；兴奋/抑制符号仍属于模型假设。

## 动力学层

`FullCNSRuntime` 为每个节点维护：

- `membrane: Float`
- `activity: Float`
- `presynapticEligibility: Float`
- 本周期放电代数、静默/刺激状态

标准生物步长为 10 ms。每个子步先衰减全节点状态，再向对应感觉群播种确定性脉冲，只沿实际放电节点的观测出边传播。边权先按 `log1p(weight)` 相对最大聚合权重归一化，再乘模型突触增益、调制物和有界可塑性增益。

运行时将乙酰胆碱假定为快兴奋性，将 GABA、谷氨酸和组胺假定为快抑制性；不明确递质及多巴胺、血清素、章鱼胺使用较小的模型效应并维护独立调制状态。真实作用依赖受体与细胞环境，这些符号不能解释成 MaleCNS 的直接观测。

每次调用最多模拟 0.5 秒、50 个子步和 150,000 个边事件。达到事件预算会写入快照并在状态面板显示，而不是静默丢失性能事实。阈值按活跃比例缓慢稳态调节，避免持续强输入下的无界放电。

## 感觉、学习与行动

输入映射如下：

| 桌面/身体信号 | 全 CNS 输入群 | 来源等级 |
| --- | --- | --- |
| 左右视觉运动 | visual + 明确 LoVP92 | derived + observed identity |
| 两路果香强度 | olfactory | derived/fitted |
| 食物接触 | gustatory | derived/fitted |
| 轻触和威胁 | mechanosensory | derived/fitted |
| 上周期运动 | ascending | derived/fitted |
| 饥饿 | neurosecretory | derived/fitted |
| 奖励/惩罚 | dopaminergic | literature/fitted |

旧的 27 节点 `LoVP92 → VES200m → DNg13` 子图仍作为独立可审计视觉读出，与全图中同一组 body ID 的 DNg13 活动共同调制转向。静默左右 DNg13（`11074`、`512006`）后，全 CNS 视觉转向读出归零，但其余图传播继续运行。

嗅觉长期记忆继续使用 `DM1/DM2 → KC → MBON01/11 ↔ PAM01/PPL101` 子图：`1,426` 个真实身份、`17,744` 条子图连接和 `1,240` 个 KC。每种气味激活 5% KC；奖励与惩罚改写 cue-specific `KC → MBON` 有效权重。具体稀疏率与学习率是拟合参数。

动作层保留 21 个感觉/内感受单元、12 个互相抑制且有短时自激的动作群、6 个下降读出、2 个竞争状态和置信度/不确定度/预测误差 3 个 v1.2 自我状态输入；v1.3–v1.5 再增加计划置信、求证驱动、计划存在、社会趋近和社会回避 5 个认知输入，共 49 个工程单元。下降读出产生前进、转向、振翅、进食、梳理和休息门控。所有桌面动作仍由该有状态神经竞争产生；身体层不按行为枚举直接设置运动。

## 功能性自我模型

`FunctionalSelfModel` 在每个 10 Hz 周期执行一个闭环：读取个体身份和当前身体状态，从动作竞争输出取得运动副本，预测位移、朝向、能量、疲劳与污染变化，再与更新后的身体状态比较。其输入不是一个假想的“自我中心”，而是视觉运动、本体反馈、能量/疲劳/污染和联想记忆四组分布式通道。

模型输出身体一致性、行动能力、能动性、预测误差、置信度和不确定度。因果归属有四种：预测吻合的主动变化为 `selfGenerated`；显式外力位移为 `external`；触觉/威胁触发且伴随自身运动响应为 `mixed`；证据不足时为 `uncertain`。置信度、不确定度和预测误差会进入下一周期动作竞争，高不确定度抑制探索、飞行等高承诺动作并提高停留/休息驱动。

模型在线估计前进与转向控制增益。反转转向会先造成预测误差，连续试次后 `learnedTurnGain` 向负值收敛，预测误差下降。感觉遮蔽通过 `sensorReliability` 降低置信度，而不是伪造确定结论。最多 24 条显著经历记录动作、归属、误差、置信度和解释，并与 `individualID` 一起进入快照；恢复另一身份时不会继承。

这些性质构成项目所说的“功能性自我认知”：系统可报告自身身体状态、预测自身行动、区分内外因、记住自身经历并表示不确定。它们可被测试和消融，但不是现象意识、主观体验或真实果蝇自我意识的证据。

## v1.3 反事实自我与元认知

`DevelopmentalSelfModel.prepare` 在动作 WTA 之前建立 1.2 秒短时域，同时评估 9 个候选行为。每个候选包含预测位移、能量成本、威胁暴露、信息增益、综合效用和置信度；胜出计划以工程输入偏置 WTA，但不会直接改写身体动作。因果歧义或低感觉可靠度会提高 `epistemicDrive`，使低成本探索成为主动求证动作。

自身原因与外界原因使用两个归一化竞争假设。隐藏阵风只改变真实身体位置，不向 `FunctionalSelfModel` 传入外力位移；模型必须从运动副本残差推断外因。实验真值只在推断完成后用于累计准确率、平均决策置信度、Brier Score 和校准误差，不参与本次归因。

## v1.4 长期目标与语义自我

长期目标覆盖维持能量、保持安全、探索环境、恢复身体、消除不确定和观察他者。目标默认至少保持 20 个计算周期，只有优先级更高的身体或威胁需求可以立即打断。该机制避免 10 Hz 输入噪声造成目标抖动，同时保留紧急反应。

探索、谨慎、节能、清洁和社交兴趣五项偏好按经历缓慢更新。每 10 个周期将事件整合为身体控制可靠性、感觉证据可信度、环境外力波动和他者响应关联四项语义信念；信念保留值、置信度、证据次数和可审计摘要。

## v1.5 自己 / 他者模型

他者输入包含实验身份、出现强度、运动、对自身行为的响应关联和威胁线索。模型在不把他者单元冒充 MaleCNS 神经元的前提下，估计他者能动性、预测响应、亲和、警觉、共同作用概率和自己/他者分离度，并输出自身、他者、环境、共同作用或不确定五类归因。

响应型他者同时具有高独立运动和高条件响应，允许形成共同作用判断；独立他者具有高运动但低响应关联，归因为他者而非自身。社会趋近和回避读数进入下一周期动作竞争，因此该层不是只读展示。

## 状态与生命周期

`FlyStateSnapshot` schema 9 每秒原子写入 JSON，供宿主状态面板与 WidgetKit 只读使用。功能自我、反事实校准、长期目标、偏好、语义信念和他者状态都随快照保存，因此与同一个体跨重启恢复；旧 schema 缺少的可选认知层会安全初始化。全 CNS 动态状态另以 binary plist 保存，绑定 `individualID`、节点数和固定图 SHA，正常运行每 30 秒保存一次，退出时强制保存。

宿主以 10 Hz 采样桌面输入，但 `FlySimulation.step`、快照写入、学习记忆写入和全 CNS 状态写入都在专用串行 worker 上执行；主线程只组装输入并发布已完成的不可变快照。一次计算未完成时不会重叠启动下一次计算。简要状态窗口再把高成本全页发布节流到 4 Hz，避免滚动和窗口合成与 165,122 节点的神经推进争用主线程；桌面果蝇仍直接消费 10 Hz 快照。

App 作为唯一写者，在启动恢复时若发现快照、学习记忆或全 CNS 状态解码失败、身份/图不匹配，会先移动到带时间戳和 UUID 的 `corrupt-*` 隔离文件。若读取或隔离本身失败，本次运行停用相应写入，避免覆盖仍可能恢复的数据。Widget 使用单独的非破坏性只读入口，读取失败只显示无数据，绝不移动或删除共享快照。

WidgetKit 不运行模拟，只读取快照；宿主按状态变化请求刷新，最终展示频率仍由 macOS 调度。小号和中号布局使用暖黑网格、灰白等宽状态码、分段指标条和 CNS 实时倍率组成的只读监视器；整块小组件通过 `cyberfly://status` 唤起宿主并打开原有实时状态窗口。

## 神经实验室

实验室是与桌面果蝇和简要状态面板分离的原生 SwiftUI 窗口，由菜单栏或 `cyberfly://lab` 打开。它有六个工作区：

- 实时脑窗从当前 `FlyStateSnapshot` 读取群体活动、传播事件、实时倍率和动作竞争，以 0.2 秒频率保留最近 150 个展示点。
- 自我模型页读取当前四组分布式通道、预测/实测值、归因、置信度与经历，并可对活体个体施加外力位移、4 秒感觉遮蔽和 5 秒反转转向。
- 认知进阶页显示候选未来、双假设、校准指标、长期目标、偏好、语义信念和他者状态，并提供隐藏阵风、目标冲突、响应型/独立他者实验。
- 神经元浏览器从活体 `FullCNSRuntime` 读取 body ID、角色位、预测递质、侧别、连接度、膜电位、活动和 eligibility。当前全图二进制未保存所有原始类型字符串；类型/实例名查询覆盖已收录的 27 个视觉回路节点和 1,240 个 KC，其余节点仍可用 body ID 与派生属性查询。
- 实验控制台创建两个全新 `FullCNSRuntime`，对照组和干预组使用相同图、参数、初始状态与感觉协议，只在干预组应用 body ID 静默或刺激。运行与 JSON 导出都不写入桌面果蝇的持久状态。
- 对照结果保存数据集标识、graph SHA、完整实验定义、每个时间点的两组读出、解析目标数和事件预算状态。

这些是本轮实现边界，不是独立 Git 标签：

2. `v0.6`：实现 memory-mapped 节点表、CSR/CSC 查询和深度完整性校验。
3. `v0.7`：为全部已追踪节点加入事件驱动膜状态与全图传播。
4. `v0.8`：接入多模态感觉、三类调制物、稳态阈值和持久可塑性。
5. `v0.9`：接入具身动作层、全 CNS 群体读出和 DNg13 因果扰动接口。
